# Lesson Booking: Interview Exercise

You're joining a small team that runs a lesson-booking app for music
teachers. Students book lessons with teachers; teachers get paid per lesson.

You have 45 minutes. Use any tools you normally use, including AI.
Please think out loud. I care more about how you work than how much you finish.
I'm your product manager and teammate: ask me anything.

## Part 1: Bug report from support

> "Two students showed up for Ms. Alvarez's 4:00pm lesson last Tuesday.
> This keeps happening with a few teachers. Please fix."

Find the cause and fix it so it can't happen again.

## Part 2: Cancellations

Students need to be able to cancel a booking. If they cancel with enough
notice, they get their money back.

Add this.
